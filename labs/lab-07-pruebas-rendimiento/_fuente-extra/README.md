# Material fuera de alcance — Fiabilidad de productores

Estas guías y scripts vienen del curso 28h y cubren **idempotencia** y **transacciones exactly-once**. Se conservan como referencia para el instructor; el tema se toca a nivel teórico en la Unidad 3 («Escalamiento y tuning de productor/consumidor»).
